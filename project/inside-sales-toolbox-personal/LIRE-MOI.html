Installer ou mettre à jour

Extraire le ZIP dans un dossier permanent. Ouvrir edge://extensions, activer le mode développeur, puis Charger l’élément décompressé et choisir le dossier solotech-lead-bridge contenant manifest.json. Pour mettre à jour ton extension personnelle existante, remplacer les fichiers dans son dossier actuel puis cliquer sur Actualiser dans Edge. Ne pas installer cette version par-dessus la version équipe.

Ouvrir D365

Le bouton ouvre la page d’accueil CAOP si D365 n’est pas ouvert. Si un onglet D365 existe déjà et que l’accès est accordé, il est affiché sans quitter le formulaire en cours.

Autorisations

À la première ouverture, cliquer sur Autoriser tous les accès puis accepter la demande Edge. Edge peut regrouper les autorisations dans une seule fenêtre. Le bouton disparaît lorsque les accès sont accordés; il revient si un accès est retiré. Les accès déjà accordés restent utilisables si une nouvelle demande est refusée. La vérification a lieu à chaque ouverture et lors des changements d’autorisations. La copie utilise uniquement l’écriture dans le presse-papiers; le collage manuel ne demande pas d’accès de lecture.

Menu clic droit

Sélectionner du texte sur une page et ouvrir le menu Inside Sales Toolbox. Préparer les coordonnées remplace le brouillon par la sélection. Ajouter au texte complète le texte brut. Utiliser comme nom, téléphone ou courriel ne remplace que ce champ et conserve les autres. Les options de casse préparent un résultat à copier sans modifier la page. Vérifier ce code HS ouvre le module HS avec la sélection.

Le menu ouvre une fenêtre Toolbox indépendante, qui reste ouverte pendant les changements d’onglet. Pour remplir D365, utiliser le bouton de l’extension depuis la soumission ou commande cible; la fenêtre indépendante utilise la page depuis laquelle elle a été ouverte et ne devine pas une autre commande.

Coordonnées client

  1. Ouvrir une soumission ou commande D365 et activer Edit.
  2. Ouvrir l’extension, choisir Coordonnées client et coller le texte.
  3. Cliquer sur Extraire les coordonnées. Vérifier et corriger le nom, téléphone et courriel, notamment si plusieurs contacts sont présents.
  4. Copier les notes ou cliquer sur Remplir dans D365 depuis l’onglet D365 actif.
  5. Vérifier les champs puis enregistrer dans D365.

Les coordonnées sont remplacées, y compris téléphone et courriel existants. Les trois renseignements sont requis avant le remplissage. Le texte collé et les champs de ce module sont enregistrés localement dans Edge à chaque saisie. Ils restent disponibles après fermeture de la fenêtre et redémarrage du navigateur, jusqu’au clic sur Effacer ces coordonnées. Le dernier module ouvert est restauré. Le formatage est local et basé sur des règles, sans IA distante : une signature complexe peut demander une correction. Les téléphones reconnus sont nord-américains.

Salesforce vers Dynamics

Le module personnel existant est conservé, y compris la création de soumission en développement. Ouvrir le guide existant.

Vérificateur HS

Le vérificateur v1.1 est intégré. Autoriser Canada.ca à son ouverture pour permettre l’actualisation. Son périmètre reste les contre-mesures canadiennes sur les produits américains. Il ne calcule pas l’ensemble des droits de douane. Vérifier la date et les messages de la source.

Validation

Formatage et simulation du remplacement des champs vérifiés. L’intégration réelle avec les contrôles D365 doit être testée dans ta session Edge. Aucun test visuel Edge n’a pu être exécuté dans cet environnement.
