Les numéros du sommaire correspondent à la pagination des PDF. La pagination Word peut varier selon les polices et le logiciel utilisé. Les séparateurs dans les sources Markdown indiquent les pages prévues.

Contenu vérifié contre le code équipe 3.5.12, son `LIRE-MOI.html`, les libellés du popup et du panneau, les règles de calcul et de conservation, les notes de publication et le guide historique. Les anciens guides sont conservés. Les PDF utilisent le logo déjà présent dans le projet et une mise en page en violet et vert; ils n’incluent pas de captures d’une session client ni de données clients réelles.

Le carnet d’utilisation couvre Salesforce vers D365, les contacts, les produits neufs et usagés (filtres, régions, Power BI et Excel), les commandes prêtes, la marge, les taxes, les devises, les codes HS, le clic droit, le lexique et le dépannage.

Cette documentation n’atteste pas d’un essai connecté Power BI/D365. Elle rappelle les limites de la publication de test 3.5.12, dont le défilement Power BI et le sens distinct d’InternalReference. Aucun fichier de l’extension, ZIP ou numéro de version n’est modifié.

Les outils Canva et le connecteur GitHub ne sont pas disponibles dans la session de rédaction. Les documents sont fournis directement en PDF et Word; l’accès Git du dépôt permet leur conservation sur une branche dédiée.
