# Inside Sales Toolbox Équipe 3.5.12

Le calculateur distingue mieux ses champs et ses actions. Les champs monétaires et les totaux affichent le symbole $ avec CAD ou USD. Les calculs, escomptes, taxes et cadenas conservent leurs règles.

Le lecteur Commandes prêtes sait manipuler la barre horizontale personnalisée observée dans Power BI. Les différents liens fournis vers Open Orders réutilisent le même rapport.

Vérifications : calculs dans les trois directions, conversions, taxes, cadenas, effacement, validation des entrées, lecteur horizontal personnalisé et routage des rapports testés localement. ZIP de 75 fichiers contrôlé octet par octet contre les sources, CRC et références locales vérifiés.

Limites : manipulation dans la session Power BI authentifiée non confirmée. InternalReference n'est pas assimilé à Internal Notes sans confirmation du champ. Cette publication reste une version de test.

Installation : décompresser le ZIP dans le dossier actuel de l'édition équipe, recharger l'extension dans Edge/Chrome, puis actualiser les onglets concernés.
